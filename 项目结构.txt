SOS_Workbench 0.1.0 项目结构

    带 ★ 的模块是平台内核。ui/ 只是内核的一个客户端。
    工具与技能通过"进程契约"接入，与平台没有 import 关系。

======================================================================
二、一次任务的调用链
======================================================================
L2 面板点「开始」
    → app._on_freedom_toggle
    → phase2.run_task(task_id, panel, target)
        → 线程 _execute_tool_chain，每一步：
            _parse_parameters        解析参数 JSON、继承上游结果/文件
            targets.redact           先生成脱敏副本（给日志）
            targets.resolve_secrets  再解析凭证（给执行）
            _step_timeout            计算进程超时
            _run_single_tool / _run_freedom_atomic / _run_skill
                → task_executor.submit        并发闸门 + run_id 登记
                    → tool_runner.run         Popen、流式读、看门狗
                        → 子进程（任意语言）
            _save_round_summary     写 storage/round/{任务}/{任务}_round_N.json
            panel.advance_round()   轮次 +1

CLI 调用链（无 GUI）
    → cli.py run
    → core/headless.HeadlessApp / HeadlessPanel
    → phase2.run_task / _execute_tool_chain    与 GUI 完全同一套执行核
    → storage/runs/{run_id}/run.json           CLI 额外写 run 记录

L3 只读消费：phase3.get_round_log / get_round_summary_text


======================================================================
三、依赖方向
======================================================================
    ui/ ──▶ app.py ──▶ phases/ ──▶ core/
     ▲         │
     └──回调───┘

    cli.py ──▶ core/headless.py ──▶ phases/ ──▶ core/

    core 不 import tkinter（编排器里改为函数内延迟导入），
    phases 不直接操作控件，
    工具与平台之间只有进程契约。


======================================================================
四、会自动重建的东西
======================================================================
    storage/projects、storage/round、storage/phase3、storage/runs   启动时缺则创建
    reports/                                          工具按需写入
    session.log、latest/、structured_logs/             有执行才产生

    删除 storage/ 不损坏程序，只丢历史记录。
    SOS_DATA_DIR 可把整个运行数据根目录移到别处（CLI/测试隔离）。


======================================================================
五、接入新领域要动哪些文件
======================================================================
    1 个文件：external_tools/你的工具（任意语言）
    0 处平台代码改动。

    这是"执行器中立"的验收标准。
